Using your friend's friend

An experienced, responsible friend can be useful for basic firearm familiarization, range etiquette, safe handling, and helping beginners get comfortable.

For Massachusetts law, this chat recommended pairing informal familiarization with a formal Massachusetts self-defense/use-of-force law class.

Suggested sequence from this chat

If the friends are beginners

  1. Beginner handgun/live-fire class.
  2. Dedicated Massachusetts law class.
  3. Defensive-pistol class later.

Top three to investigate first

  1. Mass Firearms — Self Defense Law.
  2. GOAL/Danvers — Know the Law.
  3. Tactical Dynamics — beginner + defensive firearm progression.

Massachusetts course change mentioned in this chat

This chat noted that Massachusetts changed its required Basic Firearms Safety curriculum effective April 2, 2026, including live-fire and updated legal/safety material. Verify that an LTC/basic course uses the current approved curriculum. Massachusetts source linked in the chat.
