# Items and Magic

## Inventory philosophy

Keep inventory small, visible, and meaningful. Avoid junk collection and combinatorial guessing.

Every carried object should have:
- a clear physical description;
- at least one plausible use;
- feedback for reasonable wrong uses;
- no requirement for arbitrary "use everything on everything."

## Core items

### Sun Key
Quest item. Brass/gold, sunburst bow.
Uses:
- ancient courier locks;
- Moon Bell yoke;
- proof of Aldus's errand.

Cannot be permanently lost or consumed.

### Red locksmith's thread
Starter optional item.
Uses:
- mark a fixed tree/path at Briar Crossroads;
- possibly secure a tiny mechanism or create a visible trail.
Should not become universal rope.

### Brass hand mirror
Starter optional item.
Uses:
- reflection clue;
- Moonwell beam if retained;
- shiny trade possibility.

If player gives/trades it away, another reflective route must remain available.

### Blue medicine bottle
Starter optional item.
Uses:
- hold Moonwater;
- make a glowjar after dusk with fireflies.

If unavailable, Ysabet can provide a vial on helpful route.

### Honey cake
Starter optional consumable.
Uses:
- coax Mallow;
- small character response.
Do not make it mandatory if consumed elsewhere.

### True-Path Lantern
Ysabet's tool.
Strong magical light revealing glamoured edges, hidden route contours, old courier marks.
Can be:
- lent with permission;
- taken/borrowed without permission;
- returned later.

It must not reveal every puzzle answer.

### Glowjar
Alternative to True-Path Lantern.
Blue bottle + captured fireflies after dusk.
Reveals enough of Whispering Hollow to cross, but not all later hidden details.

### Moon-disc
Polished reflective disc associated with old chapel/courier rite.
Alternative reflector for Moonwell if mirror unavailable.

### Moonwater
Small vial.
Rule: loosens living briar and wakes certain old stone enchantments.
Uses:
- Brindle's thorn-swallowed toll bell;
- late bell-tower briars;
- optional environmental reactions.

Quantity should be sufficient for required route; do not create unfair depletion.

### Bridge charm
Reward from helping Brindle.
One late-game use: calms/parts old bridge/castle briar or supports final tower mechanism.
Helpful, not mandatory.

### Rope scrap / mill favor
Potential Bram reward.
Used only if a triggered late tower state needs a pull repair or to shorten a route.
Helpful, not mandatory.

## Magic consistency

True-Path light reveals.
Moonwater loosens/awakens.
Sun Key opens old courier/bell locks.
Dusk/moonlight activates moon-specific things.

Do not invent a new magical behavior to rescue a puzzle at implementation time.
