# Milestone 07 — Blind Playtest + Polish

> **Historical office-prototype milestone — superseded.** Its old acceptance targets describe a different game. Current acceptance criteria are in [`../QUALITY_GATES.md`](../QUALITY_GATES.md); see [`../README.md`](../README.md) for current project direction.

## Goal
Make the POC feel complete rather than merely functional.

## Passes
Fresh player with no design notes; puzzle solver; narrative/continuity critic; visual critic against the KQ reference board; exploit/state tester; save/reload; performance/browser; keyboard/accessibility basics.

## Blind-review questions
- What is this game about?
- Who is Sarah?
- What motivated Daniel?
- Which puzzle required actual reasoning?
- Which decision felt uncomfortable?
- Where were you bored?
- What did you want to do that the game would not let you do?
- Which scene was visually memorable?

## Acceptance
Fix high-severity issues and repeat testing until the experience communicates the intended story without explanation from the designers.
