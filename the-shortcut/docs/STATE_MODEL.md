# Narrative / Behavioral State Model

## Truth is separate from belief
Explicitly distinguish:
- what actually happened;
- what evidence exists;
- what each NPC knows;
- what each NPC believes;
- what Daniel has claimed.

## Behavior observations
Do not store only morality points. Record contextual observations such as action category, perceived detection probability, personal benefit, likely harm to another, public/private context, initiated vs pressured, escalation, later admission/correction, rationalization, and technically-true-but-misleading behavior.

End-of-day analysis derives patterns from these observations.

## Hidden dimensions
Optional internal summaries: integrity, opportunism, courage, loyalty, self-benefit sensitivity, empathy, rationalization/self-deception, exploitation under low detection risk. Never expose them as player-facing numeric morality scores.

## Evidence
Evidence includes source, timestamp, content/state, editability, visibility, who can access it, whether altered, and provenance where relevant.

## NPC knowledge
Each NPC tracks explicit facts and, where useful, confidence/belief. Never infer omniscience from global state.
