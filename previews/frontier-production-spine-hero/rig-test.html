The Living Ox Pair

The approved Rosa Bonheur asset already contains two overlapping oxen in one painted raster sprite. This page compares that exact sprite animated two ways: the original whole-image mesh deformation versus a Spine-style weighted mesh with virtual head, neck, torso, foreleg and hindleg bones.

Baseline lab Back to game
What can this historical source prove? It can prove whether bone-weighted mesh deformation preserves painterly pixels better than broad whole-image warping. It cannot honestly prove two fully independent skeletal oxen because the rear animal is partially hidden by the foreground animal in the original painting. That final test requires purpose-painted overlapping layers with hidden anatomy.

Animation method

Same image. Same scale. Same scene. Same root travel. Weighted rig uses multiple virtual bone influence fields over a denser mesh; Whole mesh uses the original broad 11×7 deformation.

Inspection

Neutral exposes the painted sprite without environmental camouflage. Skeleton now animates the actual virtual bone endpoints so gait motion is visible rather than just numerically changing underneath a static debug drawing.

What this test answers

Readable motion: can a human immediately see walking, not merely detect changed vertices in a test?

Weight: does planted-hoof damping, hoof lift and shoulder/hip compression read better than whole-image warping?

Art integrity: do the brushwork, silhouettes and atmosphere survive the stronger deformation machinery?
