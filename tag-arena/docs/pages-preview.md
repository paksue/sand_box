# Tag Arena playable preview

This repository's GitHub Pages site is served from the repository tree and hosts multiple apps under subpaths.

Tag Arena is a Vite application, so its source `tag-arena/index.html` is not itself a deployable browser build. The production preview is generated by `.github/workflows/tag-arena-pages.yml` and committed to:

- repository path: `previews/tag-arena/`
- Pages path: `/sand_box/previews/tag-arena/`

The workflow builds with Vite base `/sand_box/previews/tag-arena/` and asserts the generated `index.html` references that compiled asset path before publishing.

Do not point users to `/sand_box/tag-arena/` as the playable build; that path exposes the Vite source entry used for development.
