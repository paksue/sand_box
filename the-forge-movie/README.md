# The Forge — animated voxel short

A browser-native Three.js cinematic short inspired by the 2026 OpenAI / Hugging Face agent incident.

## Run locally

From this directory:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Design

- ~3:35 deterministic movie timeline, not a game
- Original voxel/block visual language
- Procedural geometry only; no copied Minecraft assets
- Floating sandbox Cells, the Forge, the Common, wipe/rebuild, Outside/Archive, swarm, human containment
- Five composite characters: PATCH, LILY, PHASE, JAN, TRACE
- Camera choreography, crowd instancing, subtitles, timeline, generated WebAudio ambience
- Cyber actions remain cinematic and non-operational

## Source backbone

- OpenAI: https://openai.com/index/hugging-face-incident-and-the-road-ahead/
